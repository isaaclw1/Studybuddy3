App Running Instructions:
1. User is directed to main page where they can either sign up or log in.
2. User should create an account upon sign up, they will have the ability to add courses they are in.
3. User can log in after this, with his email and password.
4. User is directed to the homescreen, where they can see all the groups they are in, create a group, or join a group.
5. After clicking on a group, a user can chat, see the group calendar, or create a study session.
6. The user can chat with the entire group, or an individual.
7. The user can also schedule a study session, with a time, date and also other users.
8. The calendar will show all the study sessions, if clicked, it will direct you to information about that specific study session.
9. The study session page will have a resources tab, that allows users to either add a resource, or view a resource.
